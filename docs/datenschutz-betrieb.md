# Datenschutz: Betriebsnotizen

Die Besucherseite verwendet die öffentlich dokumentierten Standardbedingungen von Netlify. Sie behauptet weder einen separat geprüften Kontovertrag noch eine pauschale Protokollierungsfrist. `noindex` bleibt bis zum öffentlichen Start gesetzt.

Geprüfte Quellen am 26.10.2026:

- https://www.netlify.com/pdf/netlify-dpa.pdf (09.06.2026): Bestandteil der Standardverträge, Weisungsverarbeitung, DPF vorrangig und SCC als Auffangregelung, Unterauftragnehmer und Löschung.
- https://www.netlify.com/legal/terms-of-use/ (14.10.2026): aktuelle Kontaktanschrift 101 2nd Street, San Francisco, CA 94105. Das DPA nennt im Anhang noch 512 2nd Street; für die Anbieterbeschreibung wurde die aktuellere Website-Anschrift verwendet.
- https://www.netlify.com/pdf/self-serve-subscription-agreement.pdf
- https://www.netlify.com/legal/subprocessors/ (leitet in das Trust Center um; die vollständige aktuelle Liste war automatisiert nicht auslesbar und wurde deshalb nicht als projektbezogen bestätigt dargestellt).

Noch betrieblich zu prüfen, bevor die eigene Domain umgestellt wird:

1. Konto gehört zur Snackostore GmbH; keine abweichenden individuellen Vertragsbedingungen.
2. Netlify-/STRATO-Auftragsverarbeitungsunterlagen im Unternehmen dokumentieren. Der Website-Text ersetzt keinen Vertrag und schließt keinen Vertrag ab.
3. Tatsächliche Netlify-Protokollierungsfristen und aktivierte Zusatzdienste prüfen. Falls feste Speicherfristen bekannt werden, die Beschreibung entsprechend präzisieren. Keine 7-/30-/90-Tage-Frist erfinden.
4. Erledigte Anfragen regelmäßig in Netlify Forms UND im STRATO-Postfach auf Löschbedarf prüfen. Es wurde keine automatische Löschung eingerichtet. Aufbewahrungspflichtige Geschäftsunterlagen gesondert behandeln.
5. Das tatsächliche öffentliche Deployment ohne Vorschau-Zugangsschutz auf Cookies, Header und externe Anfragen prüfen. Der Zugangsschutz war beim letzten unauthentifizierten Abruf noch aktiv (HTTP 401).

Bestätigte Funktion: Formulareinsendung wird gespeichert, E-Mail erreicht das Geschäftspostfach, Reply-To führt zur eingetragenen Kundenadresse.
